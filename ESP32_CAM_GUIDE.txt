================================================================================
                    ESP32 CAM - DIAGNOSTIC ET CORRECTION
================================================================================

> ⚠️ Ce guide est destiné à la documentation legacy sur l'ESP32 CAM. Le projet actuel évolue vers une application Web moderne et n'utilise pas cette architecture matérielle.

PROBLÈME INITIAL:
  "JPEG format is not supported on this sensor" (Error 0x106)

SOLUTION:
  Le format JPEG n'est pas directement supporté par le capteur.
  Les fichiers créés supportent maintenant:
    1. RGB565 (16-bit color) - RECOMMANDÉ - Très compatible
    2. GRAYSCALE (nuances de gris) - Fallback
    3. YUV422 (compression sans perte)

================================================================================
                            FICHIERS CRÉÉS
================================================================================

1. esp32_camera_config.py
   - Configuration caméra avec support multiple formats
   - Détection automatique du capteur via I2C
   - Test des formats avec fallback
   - À uploader sur ESP32

2. esp32_hardware.py [MODIFIÉ]
   - Intégration de la nouvelle configuration caméra
   - Meilleure gestion d'erreurs
   - Logs détaillés pour diagnostic

3. esp32_flash_diagnostic.py
   - Script complet de diagnostic à exécuter sur ESP32
   - Vérifie santé système, I2C, caméra
   - À uploader et exécuter sur ESP32

4. esp32_flash_tool.py
   - Outil Python pour uploader et diagnostiquer
   - Détecte le port COM automatiquement
   - Gère mode REPL interactif

5. esp32_flash_tool.bat [WINDOWS]
   - Lance le script Python en automatisant les dépendances
   - Double-clic pour démarrer (Windows uniquement)

================================================================================
                          COMMENT UTILISER
================================================================================

OPTION A: Utiliser le Script Batch (RECOMMANDÉ sur Windows)
─────────────────────────────────────────────────────────────

  1. Connecter l'ESP32 CAM via USB à votre PC
  2. Double-cliquer sur: esp32_flash_tool.bat
  3. Suivre les instructions:
     - [A] Détection du port COM
     - [B] Téléchargement des fichiers
     - [C] Lancement du diagnostic
     - [D] Mode REPL interactif (optionnel)

OPTION B: Utiliser le Script Python Directement
──────────────────────────────────────────────────

  1. Ouvrir PowerShell/Terminal dans le dossier e:\SECRET FILES\MY_TFC
  2. Connecter l'ESP32 CAM via USB
  3. Exécuter:
     
     python esp32_flash_tool.py

  4. Suivre les instructions interactives

OPTION C: Upload Manuel (Avancé)
──────────────────────────────────

  Si les scripts automatiques posent problème:

  1. Télécharger Thonny IDE (https://thonny.org/)
  2. Connecter ESP32 CAM
  3. Dans Thonny, aller à Tools → Configure interpreter
  4. Sélectionner "MicroPython (ESP32)" et le bon port
  5. Drag & drop les fichiers:
     - esp32_camera_config.py
     - esp32_flash_diagnostic.py
  6. Dans REPL:
     >>> import esp32_flash_diagnostic
     >>> esp32_flash_diagnostic.initialize_with_diagnostics()

DÉPANNAGE (Si camera ne marche pas):

  1. "Aucun device I2C détecté"
     → Vérifier connexion du câble 22-broches
     → Vérifier alimentation 3.3V
     → Reset: tirer GPIO 32 en HIGH

  2. "Module esp32camera NON DISPONIBLE"
     → Télécharger esp32camera.py depuis micropython
     → Uploader via ampy ou Thonny

  3. "Tous les formats échouentt"
     → Capteur peut être endommagé
     → Vérifier tensions sur les broches
     → Tester avec une autre ESP32 CAM

================================================================================
                          DÉPANNAGE RAPIDE
================================================================================

Symptôme: "Error 0x106 - JPEG not supported"
Solution: Utiliser RGB565 (automatique maintenant)

Symptôme: "I2C scan returned no devices"  
Solution: Vérifier câble caméra et alimentation 3.3V

Symptôme: "Module esp32camera not found"
Solution: pip install adafruit-ampy, puis uploader esp32camera.py

Symptôme: "Connection refused" sur COM port
Solution: 
  1. Débrancher/rebrancher USB
  2. Vérifier le port dans Gestionnaire des périphériques (Windows)
  3. Installer CH340 driver si nécessaire

Symptôme: "Python not found"
Solution: 
  1. Installer Python 3.8+ depuis python.org
  2. Cocher "Add Python to PATH"
  3. Redémarrer cmd
