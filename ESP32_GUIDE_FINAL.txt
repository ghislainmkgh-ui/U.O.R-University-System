================================================================================
                    🚀 DÉMARRAGE RAPIDE (RECOMMANDÉ)
================================================================================

ÉTAPE 1: Télécharger Thonny IDE
──────────────────────────────

Site: https://thonny.org/
Installer avec les paramètres par défaut

⏱️ Temps: 3 minutes

ÉTAPE 2: Connecter l'ESP32 en USB
──────────────────────────────────

1. Brancher l'ESP32 CAM en USB sur le PC
2. LED peut clignoter - c'est normal
3. Vérifier dans Gestionnaire des périphériques:
   Ports (COM & LPT) → Devrait avoir "USB Serial Port (COM10)" ou similaire

⏱️ Temps: 1 minute

ÉTAPE 3: Configurer Thonny pour l'ESP32
───────────────────────────────────────

1. Ouvrir Thonny
2. Tools → Configure interpreter
3. Sélectionner: "MicroPython (ESP32)"
4. Port: COM10 (remplacer par le bon port si différent)
5. Click OK
6. Attendre quelques secondes
   → Status montre "MicroPython v1.xx.x on xxxxx"

⏱️ Temps: 1 minute

ÉTAPE 4: Uploader les Fichiers
───────────────────────────────

1. Dans l'éditeur Thonny (à droite), aller à File → Open
2. Ouvrir: esp32_camera_config.py
3. Dans la zone de gauche (File explorer), tu dois voir:
   - Haut: Fichiers de ton dossier (ordinateur)
   - Bas: Fichiers de l'ESP32 (vide pour le moment)

4. Première méthode - DRAG & DROP (plus rapide):
   • Ne sélectionner RIEN dans l'éditeur principal
   • Drag esp32_camera_config.py du haut vers le bas
   • Drag esp32_flash_diagnostic.py du haut vers le bas
   • Attendre ~5 secondes pour chaque upload

5. Deuxième méthode - SAVE AS:
   • Éditeur: File → Save As
   • Sélectionner: "MicroPython device"
   • Sauvegarder
   • Répéter avec l'autre fichier

⏱️ Temps: 2 minutes

ÉTAPE 5: Lancer le Diagnostic
──────────────────────────────

1. Dans l'explorer Thonny (bas/gauche), double-cliquer sur:
   esp32_flash_diagnostic.py

2. Dans la console (bas/droite), tu vas voir un menu ou les fichiers vont
   s'exécuter automatiquement

3. Si menu → Taper 1 pour diagnostic automatique

4. Appuyer sur le bouton RESET sur l'ESP32 CAM pour redémarrer le diagnostic

5. Attendre les logs (30 secondes environ)

⏱️ Temps: 1 minute

================================================================================
                    🔧 DEBUGGING & TROUBLESHOOTING
================================================================================

Problème: "Chip ID detected" mais rien après
───────────────────────────────────────────
→ ESP32 pas bien connecté en USB
→ Essayer autre port USB ou câble
→ Appuyer sur RESET

Problème: "Aucun device I2C détecté"
────────────────────────────────────
→ Câble caméra 22 broches pas bien connecté
→ Vérifier l'orientation du connecteur
→ Tirer GPIO 32 en HIGH (broche reset)
→ Réappuyer sur RESET

Problème: "All formats failed"
──────────────────────────────
→ MicroPython ESP32 pas à jour
→ Télécharger version récente:
  https://micropython.org/download/esp32/
→ re-flasher l'ESP32

Problème: Thonny ne reconnect pas l'ESP32
──────────────────────────────────────────
→ Tools → Configure interpreter → Click "Connect"
→ Attendre 10-15 secondes
→ Appuyer sur RESET si timeout
→ Redémarrer Thonny

Problème: Drag & drop ne marche pas
────────────────────────────────────
→ Utiliser File → Save As → MicroPython device
→ Ou ampy (mais peut avoir issues PATH):
  python -m ampy -p COM10 put esp32_camera_config.py /

================================================================================
                        ⚠️ NOTES IMPORTANTES
================================================================================

1. ALIMENTATION:
   • L'ESP32 CAM DOIT avoir 5V séparé (pas via USB pour le capteur)
   • GND doit être commun (ordinateur + ESP32 + Arduino)

2. CÂBLE CAMÉRA:
   • 22 brochesavec orientation correcte
   • Respecter le sens du connecteur (bande de traction vers avant)
   • Vérifier pas de broches tordues

3. RESET & REBOOT:
   • Appuyer sur RESET pour rebooter l'ESP32
   • Tirer GPIO 32 en HIGH pour reset du capteur caméra
   • Laisser 2-3 secondes entre les resets

4. THONNY:
   • Privilège administrateur pas nécessaire
   • Mais peut aider si problèmes de détection port COM
   • "Stop" en haut arrête le programme en cours
